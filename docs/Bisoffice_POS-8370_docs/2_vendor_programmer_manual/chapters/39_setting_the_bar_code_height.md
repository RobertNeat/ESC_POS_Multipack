## `GShn`

**Name**: Setting the bar code height

**Format**

| Encoding | Value      |
| -------- | ---------- |
| Ascii    | `GS h n`   |
| Hex      | `1D 68 n`  |
| Decimal  | `29 104 n` |

**Range**:
`1 ≤ n ≤ 255`

**Description**:

Selects the height of the bar code.

`n` specifies the number of dots in the vertical direction.

**Defaults**: `n=162`

**Reference**: `GS k`
