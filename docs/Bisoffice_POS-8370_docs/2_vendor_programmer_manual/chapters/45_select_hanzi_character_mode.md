## `FS&`

**Name**: Select Hanzi character mode

**Format**

| Encoding | Value   |
| -------- | ------- |
| ASCII    | `FS &`  |
| Hex      | `1C 26` |
| Decimal  | `28 38` |

**Description**: Select Hanzi character mode

**Note**:

For Hanzi character：

- When select Chinese character mode, the printer handles all the Hanzi code, every two bytes.

- In the first byte, the second byte of the sequential processing Hanzi code.

- When the power is turned on, the printer does not select Chinese character mode.

**Reference**: `FS .`
