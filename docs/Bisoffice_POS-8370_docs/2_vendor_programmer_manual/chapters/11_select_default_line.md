## `ESC2`

**Name**: Select default line spacing

**Format**

| Encoding | Value   |
| -------- | ------- |
| Ascii    | `ESC 2` |
| Hex      | `1B 32` |
| Decimal  | `27 50` |

**Description**: Select default line spacing for 3.75mm (30×0.125mm).

**Note**: The line spacing can be set independently in standard mode and in page mode.

**Reference**: `ESC3`
