## `ESCtn`

**Name**: Select character code table

**Format**

| Encoding | Value      |
| -------- | ---------- |
| Ascii    | `ESC t n`  |
| Hex      | `1B 74 n`  |
| Decimal  | `27 116 n` |

**Range**:

`0 ≤ n ≤ 5`
`16 ≤ n ≤ 19, n=255`

**Description**: Selects a page n from the character code table.

**Defaults**: `n=0`

**Reference**: Character Code Table
